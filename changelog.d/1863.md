### Changed

- The counter-model review prompt (`scripts/codex-review-run.sh`) no longer
  asks the reviewer to report a listed lane the plan's lanes table does not
  answer, or a missing table: `flow-plan-record.py approve` already refuses
  both. It still asks about a `will test` lane no test in the diff exercises,
  a changed output with no `Reader:` row, and stand-in tests, which the helper
  cannot catch. `tests/test_review_prompt_parity.py` holds each dropped or
  kept question against what the helper catches.
