### Changed

- `/flow:auto` has a charter, `charters/flow/auto/CHARTER.md`: what it promises
  (one open issue, a git repository with the CPP helpers, a Claude or Codex
  session, a worktree), what it refuses (work already in flight) and what it
  only recommends at Step 3, closed solely on the approver's yes (open
  prerequisites, work no longer needed, low-frequency low-severity work; never
  a security risk). An ADR that moved another way is evidence, never an
  automatic close.
- Documentation is no longer part of the flow. `/flow:auto` Step 5 is retired
  (its number is kept so citations of Steps 6-9 stay true), `/flow:finish` no
  longer runs `update_docs`, and the CPP Makefile drops that target.
- A Tier 1 documentation-only change may skip the second-model review when its
  approved plan says so. The receipt records `skipped` with the new reason
  `tier-1-docs-only`; any other unnamed reason is still refused.
- `/flow:eli5` states the existing `Lanes: none - documentation only` answer
  beside the every-lane rule, and asks the proportionality question before a
  plan is approved. `/flow:auto` asks it again when triaging review findings.
- `/flow:auto` drops from 9,816 to 9,122 words. The collapse recipe and the
  missing-helper marker-file hand-off are withdrawn as accepted limitations; the
  speckit-context state guidance, the `FLOW_CI_*` key listing and the Codex
  attribution note move to their references.
