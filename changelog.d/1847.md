### Changed

- `/codex:code_review` runs through one helper, `scripts/codex-review-run.sh`,
  instead of six shell blocks a session copied out and pasted together. The
  blocks moved unchanged, one function per stage; the markers and the findings
  format are unchanged. The command document drops from about 6,250 words to
  2,598.
- The helper ends with a verdict line: `CODEX_REVIEW: ran` (exit 0), `blocked`
  (exit 1) or `unavailable` (exit 3). A failed `codex exec` is now `unavailable`
  by the helper's own report, never a `ran` review.
- `/flow:auto` Step 6 runs the review with one bare call and reads every receipt
  flag from the transcript's `NAME: value` marker lines, so no marker value is
  carried by hand.
- The `codex exec --json` event stream goes to the retained stream file only, no
  longer also to stdout.
