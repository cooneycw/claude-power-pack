### Fixed

- `check-doc-helper-flags` reads an unescaped backtick as a nested command, as
  it already read `$(...)`: inside double quotes, inside `$(...)`, and as an
  argument in a fenced block. A helper inside a backtick substitution in a
  quoted assignment is now checked instead of being passed as message text. In
  prose a backtick stays an inline code span's edge.
- The reader is bounded (#1844): a backtick substitution holding a backslash or
  `#` is not read. Bash strips a backslash layer inside one and a `#` there can
  start a comment, so a helper inside one is counted as unchecked in its own
  stderr note, never blocked and never claimed as checked.
