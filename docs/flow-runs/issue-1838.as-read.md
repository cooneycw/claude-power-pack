## Why

skillc's skill-gauntlet (skillc #718, #720 / PR #746) checks each skill against a `CHARTER.md`: what it promises, must always do, and must never do. Round 1 (skillc #726) drafts the first charters, starting with CPP's `/flow` commands. On 2026-11-15 the owner decided where a CPP charter lives:

- **Skills under `.claude/skills/<name>/`**: `CHARTER.md` beside `SKILL.md` (#718 decision 1).
- **Slash commands under `.claude/commands/<ns>/<cmd>.md`**: `charters/<ns>/<cmd>/CHARTER.md` at the repo root. For example, `charters/flow/auto/CHARTER.md` covers `.claude/commands/flow/auto.md`.

The other two places are ruled out:

- **Next to the command.** Claude Code registers every `.md` under `.claude/commands/` as a slash command, so `.claude/commands/flow/CHARTER.md` would become a bogus `/flow:CHARTER`.
- **The `codex/skills/` mirror.** It is generated by `scripts/codex-skill-sync.py` (the header says to edit the command instead), so a charter there would be overwritten or orphaned.

## What

1. Reserve the `charters/` tree. Add a short `charters/README.md` stating the layout above and that each charter names its command in a `subject:` field. skillc's `skillc contracts` reads that field and refuses a subject that does not exist.
2. `scripts/codex-skill-sync.py`: when `charters/<ns>/<cmd>/CHARTER.md` exists, copy it into the generated `codex/skills/<ns>-<cmd>/CHARTER.md` with the GENERATED header, so Codex users see the promise as well. The mirror stays a copy and is never the source.
3. Make sure no command-discovery or skill-coverage check treats `charters/` as commands or skills. A negative control: a `charters/` file must not appear in the command list.

No charter content is written by this issue. The drafts are produced by skillc #726, and the owner confirms them. Until then they live in skillc's `docs/measurements/round1/`.

## Acceptance

- [ ] `charters/README.md` documents the layout and the `subject:` field.
- [ ] codex-skill-sync copies a planted `charters/flow/auto/CHARTER.md` into the mirror. With no charter it copies nothing. Both cases are committed.
- [ ] A planted `charters/` file is not registered as a command or counted as a skill.
