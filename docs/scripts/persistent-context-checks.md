# Persistent-context checks - script reference

Per-script history, indexed from [the scripts inventory](../scripts.md).

## Persistent-context checks and knowledge graduation

- `check-claude-md-budget` - enforces a word ceiling on an always-loaded agent document; `make claude-md-budget-check`, folded into `make verify`
- check-claude-md-budget takes a positional document and `--budget` (#1071), so ONE instrument caps both always-loaded agent files: `claude-md-budget-check` runs it bare (`CLAUDE.md`, 2,000) and `agents-md-budget-check` as `AGENTS.md --budget 450`. A second 54-line copy was the alternative and was refused - it would be a second place for the measurement to drift, and its budget would be enforced by nothing that also enforces this one. The defaults are the pre-#1071 behaviour exactly, and `tests/test_check_claude_md_budget.py` pins the default report string because ADR 0008 row 28 records it; deriving the label from the path stem rather than the filename renames it to `claude-budget`, which reads as cosmetic and is a changed published verdict
- check-claude-md-budget `--commands` (#1669) applies the same count to EVERY document under `.claude/commands/`, against the budgets declared one per line in `.claude/command-word-budgets.tsv`: `command-docs-budget-check`. It fails a document over its budget, a document with no declared budget, a table entry whose document is gone, a table line it cannot parse, and an empty population. It has its own control (`controls/command-docs-budget`) because a control carries one invocation and the two modes read different populations
- check-claude-md-budget's AGENTS.md budget is a SIZE LIMIT, and the #1071 POST-MERGE counter-model review found the original claim here false. It rejects APPENDING CLAUDE.md's Core Directives block (389 words) to AGENTS.md's content (308) - that lands at 697, refused by 247 - and it does NOT forbid restating the rules, which is what the original text claimed: a document that deletes the Codex-specific content and pastes the block in its place measures 399 words and passes, verified rather than reasoned about. The semantic property, that no sentence in AGENTS.md explains a Core Directive, stays with review; widening this instrument to enforce it would buy the parity instrument the thin-pointer design exists not to need. The budget is defined once in `DOCUMENT_BUDGETS` and resolved from the document name, because the Makefile and CI step passed `--budget 450` as a literal and the regression test therefore guarded a constant production never read
- check-claude-md-budget gained its committed control in the same commit as the parameter (`controls/claude-md-budget`), because changing an instrument is the Negative Control rule's second clause. Its anchor is CONSTRUCTED and deliberately not the pre-#1071 script: that version carries `--root`, can be pointed at a case tree, and exits 1 on the known-bad case - it DETECTS the input an anchor must miss. The blind check is presence-and-non-emptiness mistaken for size
- `check-claude-md-links` - resolves relative Markdown links and backtick paths under an explicit prefix list, avoiding false positives from inline commands and flags; since #1037 also asserts every on-disk `docs/agents/*.md` file is referenced by CLAUDE.md's Project Map, `UNKNOWN` (exit 2) when the disk glob falls below its membership floor; `make claude-md-links-check`, folded into `make verify`
- `check-claude-md-behavior` - checks the committed pre-#724 obligation slugs remain findable across the compact root. Since #1669 it also checks each trimmed command document against a fixture of its pre-trim executable steps (`COMMAND_STEP_FIXTURES`; `flow/auto.md` is the first) and requires every step in the document ITSELF - a step found only in the linked reference is a finding, and so is a deleted fixture. In CI since #1145; before that it ran only inside `make verify`, and #1144 merged green over its red - it deleted the sentence the `project-next-vendored` obligation required and left the obligation standing, so main was red on `make verify` from the moment it landed while the pipeline reported success file, docs, and referenced skills; named-reason retirements permit deliberate future removal, and a locality rule rejects a duplicated normative lifecycle table; `make claude-md-behavior-check`, folded into `make verify`
- `knowledge-graduation-check` - validates every completed-spec acceptance criterion, durable artifact, and task resolution; refuses deletion of independently valuable contracts; writes reader-compatible version-1 entries to `.specify/graduation-ledger.json` through a per-path flock and atomic replacement
- `check-version-consistency` (#1037) - derives every place that states the project's CURRENT version (the literal "Current version:" phrase, README's bold release banner, the topmost CHANGELOG/README release heading) and fails on disagreement with `pyproject.toml`; `UNKNOWN` (exit 2) when fewer than `MIN_LOCATIONS` are derived, so a reworded phrase cannot make drift read as clean; `make version-consistency-check`, folded into `make verify`. It also reads `uv.lock`'s own-project entry (#1348): the `[[package]]` whose name equals `[project].name` (PEP 503-normalised) AND whose source is local (`virtual`/`editable = "."`), so a same-named dependency is never compared as ours. A mismatch fails like any other location. No lock, an unparseable lock, no project name, zero or several own entries, or an entry with no version is `UNKNOWN` (exit 2), never consistent. The lock is checked apart from `MIN_LOCATIONS`, so this always-present site cannot satisfy the floor that guards the derived scan
- `check-unicode-dashes` (#1037) - scans tracked `.md` files for U+2014/U+2013 outside fenced code blocks, enforcing CLAUDE.md's "single dashes" directive for the population it can actually check; deliberately excludes `vendor/project_next/**` (a neighbour's pinned content) and non-markdown source (comments need per-language parsing, filed to the Nit Store, issue #864); `UNKNOWN` (exit 2) below a tracked-file-count floor; `make unicode-dashes-check`, folded into `make verify`
- `check-md-relative-links` runs in CI since #1460 (the `md-relative-links-check` step, after `git-stage`); on a clean checkout it also catches a link to a gitignored file. Backtick and `path:line` citations stay unchecked by RULING (#1460): of 40 line-bound citations, 0 were confirmed rot, and R11's case was content drift that no existence or bound check sees. The evidence is in the script's docstring and the backlog is on #1460.
- `check-md-relative-links` (#1413) - every inline relative markdown link in a tracked `.md` file resolves to an existing file, relative to the linking document; generated mirrors, templates, run records, controls and test fixtures are excluded by prefix, and an empty population or zero links examined is `UNKNOWN`, never clean. Chosen over backtick-path scanning, which reported 35 findings over its narrowest population of which only a handful were rot.
- `check-co-authored-by-trailer` (#1037) - a `git grep` tripwire for a `Co-Authored-By:` trailer naming a pinned Claude model+version literal, the exact defect that let "Claude Opus 4.6" go stale in 8 instructional locations and, in `scripts/project-init.py`, one executed commit-message constant; `UNKNOWN` (exit 2) when `git grep` itself fails rather than finding nothing; `make co-authored-by-trailer-check`, folded into `make verify`
