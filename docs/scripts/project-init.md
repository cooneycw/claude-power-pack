## `project-init`

- project-init - deterministic scaffold planning and application engine (#721): validates and resolves Python, Node, Go, or Rust inputs into immutable file-write and structured-command data with a stable SHA-256 fingerprint; the only intentional characterization differences are resolved source placeholders and `git init -b main`. Apply uses an injectable executor, atomic per-project state at `.claude/project-init-checkpoint.json`, semantic completed-step names, and an external flock so checkpoint state is not staged. `--dry-run` prints byte-stable plan JSON without mutation; `--resume` distinctly refuses schema-version drift, fingerprint drift, semantic step-layout changes, ordinal/unknown completed steps, and filesystem changes to completed scaffold writes before skipping any recorded work
- project-init destination-first Wayfinder gate (#722): the pure clarity x session-count classifier preserves the narrow unclear multi-session trigger and the opening no-fog escape. Explicitly approved maps persist decision questions, fog, out-of-scope items, blocking edges, and a computed frontier at `.claude/wayfinder-map.json` with the same flock/atomic-write discipline as scaffold checkpoints; schema-version and immutable destination/project fingerprint drift refuse resume distinctly. A fully resolved map proposes only an `active`, transitional specification linked to its map and decision evidence, never production implementation or tracker mutation. The Wayfinder concepts are adapted from upstream author Matt Pocock's `mattpocock/skills` project under the MIT license; they are adapted, not vendored, and no upstream content is fetched at runtime
