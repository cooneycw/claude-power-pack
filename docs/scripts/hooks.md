# `hooks` - reference

Per-script history, indexed from [the scripts inventory](../scripts.md).

## `hooks`

- hooks
- `hook-mask-output` - reads a Claude hook-shaped JSON payload on stdin and filters its `tool_output` field through the sibling `secrets-mask.sh`. **It is not registered as a hook and CPP does not mask tool output** (#1206, Decision 1: the declaration lived in `.claude/hooks.json`, which Claude Code never loads, so the protection was asserted for months and never ran). It is kept because it works and because `/security:*` uses it against files AT REST, where a false positive costs a glance rather than corrupting a live channel. Do not read its existence as evidence that anything is being masked
- `hook-permission-census` - PermissionRequest hook and the ONLY honest source for the `permission-prompt` friction class (#482). The model cannot tell a manually approved tool call from an auto-allowed one - they are identical in the transcript - so model-driven capture for this class never fired; the hook fires at the moment the dialog is shown, across every session rather than only flow runs. Records one friction entry per prompt via `friction-log.sh`, carrying a risk tier from CPP's permission taxonomy and a narrowest candidate allow rule. The candidate is emitted ONLY for the safe tiers (read-only and reversible local writes); a risky prompt is recorded with its tier and NO rule, so a command approved once under pressure never becomes a blind allowlist entry
- `hook-pending-retro` - SessionStart hook that surfaces counts of pending retro material and points at `/self-improvement:retro`; it never codifies, applies or blocks. OPT-IN by design. CPP ships no hooks file into user projects at all (#1206 removed the `.claude/hooks.json` `/cpp:init` used to copy), and registering this one by default would be the imposition the feature exists to avoid (PR #527/#529); `/cpp:init` and `/cpp:update` OFFER to register it in the user settings file, default N. Reads only: the durable friction buffer (same precedence as `friction-log.sh`, so it works from inside a `/flow:auto` worktree), the `.claude/learnings.md` entries still awaiting a decision, and installed-helper drift reported by `install-drift.sh`
- `ci-provider-advisory` - prints one line when the project it is pointed at has no usable recorded CI provider (`pipeline.providers`), so the stop in `gh-pr-merge.sh` (exit 13) is heard before a merge is attempted rather than under a held merge lock (#1677). Asks the one canonical reader and never parses the record itself, so a linked worktree sharing the main checkout's untracked record reads as recorded. Silent when recorded, when the repository shows no stake in CI or CPP, and when it could not ask; exit 0 always. Called by `hook-pending-retro` (suppress with `CPP_HOOK_SKIP_CI_PROVIDER=1`) and by `/cpp:update`
