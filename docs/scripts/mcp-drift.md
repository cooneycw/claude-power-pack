## `mcp-drift`

- mcp-drift
- mcp-drift image-tag provenance (#634, the image half of #520) - a tag run by a FOREIGN-LIVE container (the external second-opinion stack's own `mcp-second-opinion:dev` / `aws-secrets-agent:dev`, built by its compose) is protected: excluded from presence and from every teardown offer, so a migrated host stops reading ORPHANED forever and `/cpp:update` cannot offer to `docker rmi` an image out from under the running external stack. Liveness rides the #520 rule (a stopped foreign container protects nothing); unreferenced tags and tags run only by stale CPP containers stay legitimate orphans; the report names the exclusion ("N protected: run by external stack") rather than hiding it; digest-form refs protect no tag (the container itself stays #520-protected)
- mcp-drift unreadable-docker honesty + name-collision caution (#673) - a refused docker socket is no longer read as an empty host: `probe_docker()` distinguishes three states, and `unreadable` (permission denied / dead daemon) classifies EVERY curated server `UNKNOWN`, suppresses the "No orphaned Docker MCP servers detected." banner in favour of a loud `DOCKER UNREADABLE` block, and exits **3** - distinct from 0 (clean) and 1 (orphans) so `/cpp:update` Step 6c, `/cpp:status` and `drift-detect.sh` branch on "could not assess" instead of relaying silence as a positive finding (they used to; a host with two retired containers running reported clean). A permission-shaped refusal is retried once via non-interactive `sudo -n docker` (never prompts, `--no-sudo` opts out); when that retry is what worked, `--plan` and `--teardown` both carry the `sudo -n` prefix so the elevation is visible before confirmation rather than discovered as a wall of permission-denied warns. A MISSING docker binary is deliberately NOT unreadable - nothing runs under a runtime that is not installed, and since #469 a docker-less host is normal, so it stays a clean read that the report names rather than hides. Third status `NAME COLLISION` covers the evidence #520/#634 provenance cannot see (a retired name live as a host process or proxy, not a visible container): a would-be orphan whose declared port answers on localhost, or which a live `claude`/`codex` registration targets, is reported with its evidence and hard-refused for teardown instead of being called an orphan
