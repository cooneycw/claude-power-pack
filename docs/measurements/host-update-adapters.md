## Discrimination evidence

The registered fidelity control passed all nine cases: three GOOD, four BAD
and two UNKNOWN. Its constructed always-current verifier misses all four BAD
inputs (stale, missing, edited and foreign members); the blind revision/lock
results are explicitly declared. The runner's whole-tree preservation oracle
suppresses detector output on writes, so a verifier mutation is not credited
as successful detection. This is a constructed anchor, not a historical one.

Additional temporary mutations were run through the actual adapter tests and
then restored. Bypassing the pinned report validator gives four failures for
empty, zero-count, wrong-revision and inconsistent-summary producers. Creating
locks during verify gives one failure with three unexpected lock files.
Ignoring member differences gives two failures, independently for byte-only
and mode-only changes. Disabling the publication preservation guard in an owned
committed source fixture gives one failure: an edited former topic is deleted
and refresh incorrectly returns current. The unchanged core has no committed
mutation or API change. These runs prove the tests distinguish those faults;
they are not regressions against an implementation predating B1.

Bypassing the driver lock only in the actual competing AGY worker processes
also fails the schedule's required `blocked` handshake. Parent setup retains
real locks; this result is not a failure to establish the lock precondition.

Final pre-freeze focused cut: `make test-host-update-adapters` passed all 39
tests in 314.73 seconds. This includes exact legacy bootstrap, failed metadata
publication reporting, reviewed qualified adoption with retained personal-byte
backup, byte-only/mode-only damage, moved source and unrelated-repository cwd.
The final fidelity control and lint/typecheck runs also passed. Separate
frozen-head full-gate and depth-1/umask-000 evidence remain required before PR.

The preliminary unchanged-consumer run passed 49 core tests, 26 pi tests and
seven independent AGY/Codex parity tests. One pi test skipped because it needs
real root. Lint, type checking (558 files), host-surface declaration coverage,
binary guards and negative-fixture checks passed. HOST-SURFACE declarations
are authored coverage, not an observed complete host-write trace.
