# `scripts/` inventory

One line per script. Each script's behavioural history lives in its own file
under [docs/scripts/](scripts/README.md), loadable alone (issue #1672; before
that this file held every history, about 93,000 words).

**Adding a script:** add one line here. Write `docs/scripts/<stem>.md` when the
script has history worth keeping, and link it from that line. History never
goes in this file.

The **population** of this file is derived and checked: `make scripts-inventory-check`
(`scripts/scripts-inventory-check.py`, issue #1013) fails when a file in `scripts/`
has no line here, or when a line names no file in `scripts/`. The set is read from
the DIRECTORY, not from `git ls-files`, so an untracked file in `scripts/` counts
locally and does not exist in CI's clean clone (#1273). An entry that is
legitimately about something other than one script is declared on the marker below.
